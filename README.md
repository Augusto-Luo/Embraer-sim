# Embraer sim

Godot 4.7 / GDScript / Forward Plus 的桌面飞行训练原型，包含 KC-390 与 EMB-314 的飞行、追击、空战和万圣节夜航任务。全部运行资产已随工程附带，无需额外插件。

## 启动

1. 用 **Godot 4.7 或兼容版本**导入根目录的 `project.godot`。
2. 等待首次资源导入完成，按 **F5** 运行，进入任务选择界面。
3. 也可以在工程目录执行：

```bash
# Godot 已在 PATH 中
./run.sh

# 或显式指定 Godot 可执行文件
GODOT_BIN=/path/to/Godot ./run.sh
```

`run.sh` 不包含任何个人机器路径。工程根目录就是 Git 仓库根目录。

## 任务

- **01 / AIRFIELD**：KC-390 机场滑跑、起飞、绕场、进近与着陆；左右驾驶座复用实体玻璃 HUD，飞控与运输机参数保持不变。
- **02 / PURSUIT**：高空追击 KC-390，完成尾后保持后进行武器练习。
- **03 / FREE COMBAT**：海岸自由飞行与模拟空战。
- **04 / GROUND ATTACK**：城市海岛地图与对地攻击任务。
- **05 / OPERAÇÃO ECO**：万圣节夜航任务，从驾驶席驾驶 KC-390 调查 ECO-13 异常信号、稳定伴飞，经历约 14 秒同相机一镜到底的巨兽显现后，直接进入无时限自由飞行。全程空中飞行，无武器；可自由抵近、绕飞与观察巨兽。葡语任务指引保留 `CENÁRIO FICCIONAL`，所有呼号与事件均为虚构。

## 操作

| 输入 | 功能 |
|---|---|
| ↑ / ↓ | 增加 / 减少油门 |
| W / S | 俯仰，方向取决于设置中的 Invert pitch |
| A / D | 左右滚转 |
| Q / E | 左右偏航 |
| Shift | 减速板 / 第一关地面刹车 |
| G | KC-390 起落架（第一、第五关） |
| C | 标准 / 远景镜头 |
| 1 | 追机 / 座舱视角 |
| 2 | 座舱内切换座位 |
| 按住鼠标右键并移动 | 追机视角自由观察；第五关 `free_flight` 也支持座舱内观察 |
| M | 回正追机视角 |
| V | 静态观察模式 |
| T | 战斗关卡切换目标 |
| Space | 战斗关卡机炮 |
| F | 战斗关卡发射导弹 / 火箭弹 |
| P | 暂停 / 继续 |
| R | 重新开始当前任务 |
| Tab / Esc | 打开 / 关闭设置 |

第五关：按标记接近 ECO-13，在提示距离内保持稳定伴飞。失联后进入约 14 秒的连续座舱镜头：先长焦聚焦双眼，再拉回展示两次更明亮、停留更久的闪电中的巨翼。镜头始终使用同一台相机，舱内原有按钮与标识提供微弱的绿色、琥珀色背光，实体 MFD 保持可读。演出中的主任务框、目标标记与大无线电框淡出，仅保留简短字幕；显现镜头前移时抑制玻璃上的 HUD 符号。

显现结束后直接进入 `free_flight`，四个眼状翼纹持续发光，月光逐渐增强。任务导航、距离目标、偏航与计时失败判定随之解除；自由探索没有退出航点或出口结算。此时可自由抵近与绕飞，按住鼠标右键观察，使用 1、2、C 切换镜头和座位。低头或转头后，HUD 随真实玻璃离开视线自然不可见；回望玻璃时在其孔径内重新看到符号。Enter 可跳过演出并直接进入同一自由飞行状态；P 暂停、Tab 打开设置，恢复后继续同一时刻。任务与音效在暂停、设置及观察模式中冻结。第五关直接替换原拦截任务，不含版本切换；所有新增演出与照明只作用于第五关，第一至第四关保持各自行为，飞机仍由真实飞行模型驱动。

第一、第五关的 KC-390 座舱共用原模型现有的 HUD combiner 玻璃，移除屏幕上的大刻度带、姿态梯与雷达。玻璃减淡绿色底色，仅符号发亮；两关的左右驾驶座分别使用对应的玻璃，教员位、外部视角与第五关显现镜头抑制 HUD 字符，暂停提示和设置菜单继续可用。第一关仅复用玻璃 HUD，其地面操作、飞控与运输机参数保持不变；第五关的夜景照明与演出继续只作用于第五关，第二至第四关保持原有显示。符号沿视线方向作近似准直投影（approximate collimation），由真实玻璃孔径裁切，不移动原模型的玻璃；这是一套简化的模拟显示，并非 KC-390 原厂航电的精确复刻。

玻璃 HUD 仅显示 IAS 空速（节）、BARO 高度（英尺）、航向、俯仰姿态梯、由实际飞行速度与垂直速度计算的飞行轨迹标记（FPV）、垂直速度（英尺/分钟），以及 GEAR、BRAKE、STALL 提示。原模型玻璃偏离机头基准轴，真实 FPV 可能处于玻璃视场外，显示不会把它强行居中。机载 MFD 的原有显示和单位保持不变。

键位、飞行手感、视角、云景和辅助瞄准可在右侧设置页调整。设置保存到各关对应的 `settings-level*.cfg`。

## 发布内容

- `project.godot`：工程入口与渲染配置。
- `scenes/`：任务选择与飞行场景。
- `scripts/`：飞控、任务、镜头、HUD、武器与设置逻辑。
- `shaders/`：云层、地面、海面、引导和特效材质。
- `assets/`：模型、纹理、字体、音频及署名文件。
- `settings*.cfg`：当前各关的默认手感配置。
- `run.sh`：可移植启动脚本。

`.godot/`、测试预览、历史工程、日志、截图、备份与其他临时文件不属于发布内容，并已在 `.gitignore` 中排除。首次导入产生的本地缓存不应提交。

## 资产与剧情说明

第三方模型、城市和机场资源的来源与署名见：

- `assets/kc390-ATTRIBUTION.md`
- `assets/mothman/ATTRIBUTION.md`
- `assets/aerodrome-ATTRIBUTION.md`

全息头像为本项目生成资源。第五关任务明确标记为虚构情境；ECO-13 为虚构呼号，异常通信为剧情演出。万圣节版复用现有 CC BY 4.0 KC-390 模型和云纹理，并加入用户提供的 CC BY 4.0 Eclipsis Mothman 模型；红色翼纹发光、巨兽滑翔和分层云幕均由本地脚本驱动。座舱背光沿用原模型按钮与标识的纹理和 UV；HUD 使用透明纹理和自制视线投影 shader，在原有玻璃内绘制发亮符号，不新增悬浮界面或整块绿色发光面板。新增 HUD 脚本与 shader 为项目自制，未引入新的外部资产，复用字体的许可证见 `assets/fonts/VT323-OFL.txt`。显现结束后，巨兽留在三维世界中滑翔，四眼持续发光，供玩家在逐渐增强的月光下自由观察。新增原创合成远雷、近雷与气压滑翔声音的来源、许可和可复现生成器见 `assets/audio/halloween/ATTRIBUTION.md`。
